# 可选传输的统一升级架构

状态：实施中的设计基线。FoE 是默认入口；其他入口只有接入并通过验收后才声明支持。

## 边界

数据流：传输协议适配器 → 独占会话管理 → 升级引擎 → 目标存储驱动。
EFW 解析、身份检查、验签、防回滚和提交属于升级引擎；协议应答、包序号、重传和入口鉴权属于适配器。
不为 UART、CAN、USB、网络预先创建空实现。第二入口先用宿主文件流验证通用契约，再按产品需求接入实际外设协议。

现有同步核心依赖 WRQ 文件名解析，异步核心公开了 SSC 类型。迁移须逐步去除这些依赖，不能把调用旧 FoE API 的包装直接宣布为传输无关引擎。
现有 API 保留兼容路径；EFW 格式及目标驱动接口不因新增传输改变。

## 会话契约

- 引擎的一个实例同时只允许一个所有者。begin 成功后返回非零会话代号；write、finish、cancel 必须提交同一代号。拒绝其他所有者时不修改当前会话。
- 代号单调递增，到达上限后拒绝新建，不能回绕复用旧代号；重建管理器前须保证旧调用者已退出。
- begin 声明目标和候选版本等请求元数据。适配器不提供物理地址；EFW 头必须与已声明身份交叉核对。FoE 仍先解析并验证请求文件名。
- write 接收有序字节流。通用接口的零长度 write 是无操作；finish 是唯一正常结束操作。FoE 适配器负责转换其零长度结束包。
- write/finish 返回完成、等待或失败。完成才表示该操作可被确认；finish 完成必须意味着回读、验签及提交均成功。
- 一次仅允许一个等待操作。等待时输入内容由引擎持有，调用方可复用接收缓冲；poll 推进同一操作，不重做已完成的写入。具体缓冲容量在初始化时固定，超限在任何存储副作用前拒绝。
- 协议重传由适配器识别；不能靠“相同字节”判断是否为重复，因为相邻合法块可能相同。FoE BUSY 门控继续保留协议包身份。
- cancel 终止等待操作和整个会话，驱动与验签资源按既有契约清理一次。初始化失败的驱动自行清理；提交成功后取消不能撤销提交。
- 会话管理器不提供线程安全。所有入口、poll、超时和取消须由同一执行流串行调度；ISR 只移交事件。
- 超时由拥有会话的适配器或上层调度器触发 cancel；管理器不绑定系统时钟。断链不等于掉电恢复，掉电安全仍由存储事务及启动检查保证。

## 编译选择

FoE 默认启用；宿主文件流入口显式启用。后续硬件传输各自独立选择源文件和接收缓冲。
通用会话管理和 EFW 引擎不包含 SOES/SSC 头，不使用 FoE 错误码作为通用状态。
默认构建继续运行现有测试；入口关闭时从构建源列表中移除，而不是仅依靠运行时分支。
多入口共享引擎会话和操作缓冲，协议接收缓冲归各入口所有。

## 分步实施与验收

每一步独立提交；行为代码先写失败测试。任何一步失败先修正，不将未验证功能标为完成。

1. 设计基线（本文）：明确会话、等待、缓冲、所有权和兼容边界。
2. 通用独占会话原语：无协议和硬件依赖，验证争用、过期代号、重复释放和代号溢出；先不改变现有适配器行为。
3. 请求身份与传输解耦：提取目标/版本的通用 begin 路径；FoE 文件名预检仍保持原有拒绝与自愈语义，保持同步核心异常清理和安全测试通过。
4. 同步字节流接口：显式 finish、零长度 write 无操作、统一结果及 owner 检查；验证错误入口不能写入或中止另一会话。
5. 异步公共接口：移出 SSC 结果类型，建立通用 start/poll/cancel 和缓冲契约；SSC gate 负责转换通用结果并保留重试确认规则。
6. FoE 接入与开关：SOES/SSC 使用统一入口；默认启用，关闭后通用引擎可独立链接；保留旧 API 兼容测试，禁止混用新旧入口管理同一引擎。
7. 宿主文件流第二入口：只作为参考传输，复用同一 EFW 和驱动，验证 FoE/文件流争用及相同固件的成功、CRC/验签失败结果一致。
8. 收尾：默认/关闭 FoE 构建矩阵、同步/异步契约、六组全量回归、文档与公开支持范围核对。

每个涉及现有升级路径的步骤运行 make test、make test-asan、make test-sentinels；涉及 SOES/驱动/密码学边界时再运行固定源码的 test-soes、test-bootloader、test-monocypher。最终收尾全部运行。

- 下一步：异步公共接口与 SSC 类型解耦。
